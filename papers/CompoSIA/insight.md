## 1. 研究动机与问题定义

### 1.1 核心问题

自动驾驶面临的主要挑战是**长尾安全关键边缘情况**，这些情况通常来自常见交通元素的**不寻常组合**。

**核心挑战**：
- 真实世界中边缘情况罕见但后果严重
- 手工定义场景无法覆盖组合爆炸的场景空间
- 需要自动合成这些场景用于压力测试

### 1.2 现有方法的局限

当前**可控生成模型**存在以下问题：

| 问题 | 描述 |
|------|------|
| **控制不完整** | 无法独立控制场景的所有关键因素 |
| **控制纠缠** | 场景结构、对象身份、自车动作等因子相互纠缠 |
| **身份编辑困难** | 难以在保持姿态不变的情况下替换对象身份 |
| **动作控制弱** | 对生成场景中对象动作的控制精度不足 |

### 1.3 研究目标

开发一个**组合式驾驶视频模拟器**，能够：
- **解耦**交通因子（场景结构、对象身份、自车动作）
- 支持**细粒度控制** diverse 对抗驾驶场景
- 实现**身份替换**（单参考图像，姿态无关）
- 提供**分层动作控制**机制

### 1.4 核心挑战

| 挑战 | 描述 |
|------|------|
| **因子解耦** | 如何分离场景结构、身份、动作等纠缠因子 |
| **身份注入** | 如何从单张参考图像注入身份，且与姿态无关 |
| **动作控制** | 如何实现精确的动作跟随和控制 |
| **对抗组合** | 如何将安全元素组合成危险配置 |

#### 3.2.1 身份编码器

```python
class IdentityEncoder(nn.Module):
    def __init__(self, backbone='resnet50', embed_dim=512):
        super().__init__()
        # 使用预训练 backbone 提取身份特征
        self.backbone = torchvision.models.resnet50(weights='IMAGENET1K_V1')
        self.backbone.fc = nn.Identity()
        
        # 身份投影
        self.projector = nn.Sequential(
            nn.Linear(2048, 1024),
            nn.GELU(),
            nn.Linear(1024, embed_dim)
        )
    
    def forward(self, ref_image):
        # ref_image: [B, 3, H, W] 单张参考图像
        features = self.backbone(ref_image)  # [B, 2048]
        identity_embed = self.projector(features)  # [B, 512]
        return identity_embed
```

#### 3.2.2 噪声级注入机制

```python
class NoiseLevelIdentityInjection(nn.Module):
    def __init__(self, embed_dim, latent_dim):
        super().__init__()
        # 将身份特征映射到噪声空间
        self.noise_mapper = nn.Sequential(
            nn.Linear(embed_dim, latent_dim),
            nn.GELU(),
            nn.Linear(latent_dim, latent_dim)
        )
    
    def forward(self, noisy_latent, identity_embed, t):
        """
        在噪声潜变量中注入身份特征
        
        Args:
            noisy_latent: [B, T, C, H, W] 扩散过程的噪声潜变量
            identity_embed: [B, D] 身份嵌入
            t: 扩散时间步
        
        Returns:
            conditioned_latent: [B, T, C, H, W] 条件潜变量
        """
        # 映射身份特征到噪声空间
        identity_noise = self.noise_mapper(identity_embed)
        
        # 调整形状以匹配潜变量
        B, T, C, H, W = noisy_latent.shape
        identity_noise = identity_noise.view(B, 1, C, 1, 1).expand(-1, T, -1, H, W)
        
        # 在噪声空间注入（加权融合）
        # 早期时间步注入更多身份信息，后期减少
        alpha = self.compute_alpha(t)
        conditioned = noisy_latent + alpha * identity_noise
        
        return conditioned
    
    def compute_alpha(self, t):
        # 时间依赖的注入权重
        # 早期时间步（高噪声）注入更多身份信息
        return torch.exp(-t / 500)  # 示例衰减函数
```

```python
class GlobalActionBranch(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim):
```

#### 3.3.2 局部动作分支

```python
class LocalActionBranch(nn.Module):
    def __init__(self, input_dim, hidden_dim, output_dim, num_objects):
        super().__init__()
        self.num_objects = num_objects
        # 每个对象独立的动作编码器
        self.object_encoders = nn.ModuleList([
            nn.Sequential(
                nn.Linear(input_dim, hidden_dim),
                nn.GELU(),
                nn.Linear(hidden_dim, output_dim)
            ) for _ in range(num_objects)
        ])
    
    def forward(self, local_actions):
        """
        编码局部对象动作
        
        Args:
            local_actions: [B, T, num_objects, local_dim] 各对象动作序列
        
        Returns:
            local_embed: [B, T, num_objects, output_dim] 局部动作嵌入
        """
        B, T, N, D = local_actions.shape
        outputs = []
        for i in range(N):
            obj_action = local_actions[:, :, i, :]  # [B, T, D]
            obj_embed = self.object_encoders[i](obj_action)
            outputs.append(obj_embed)
        
        local_embed = torch.stack(outputs, dim=2)  # [B, T, N, output_dim]
        return local_embed
```

#### 3.3.3 动作融合模块

```python
class ActionFusionModule(nn.Module):
    def __init__(self, global_dim, local_dim, hidden_dim, output_dim):
        super().__init__()
        # 全局 - 局部融合
        self.fusion = nn.Sequential(
            nn.Linear(global_dim + local_dim, hidden_dim),
            nn.GELU(),
            nn.Linear(hidden_dim, output_dim)
        )
        # 自适应权重
        self.global_weight = nn.Parameter(torch.ones(1))
        self.local_weight = nn.Parameter(torch.ones(1))
    
    def forward(self, global_embed, local_embed):
        """
        融合全局和局部动作嵌入
        
        Args:
            global_embed: [B, T, global_dim] 全局动作嵌入
            local_embed: [B, T, N, local_dim] 局部动作嵌入
        
        Returns:
            fused_embed: [B, T, N, output_dim] 融合后的动作嵌入
        """
        B, T, N, _ = local_embed.shape
        
        # 广播全局嵌入到各对象
        global_expanded = global_embed.unsqueeze(2).expand(-1, -1, N, -1)
        
        # 拼接
        combined = torch.cat([global_expanded, local_embed], dim=-1)
        
        # 融合
        fused = self.fusion(combined)
        
        return fused
```

```python
    def __init__(self, unet, action_dim):
        super().__init__()
        self.unet = unet
        # 动作条件投影
        self.action_projector = nn.Sequential(
            nn.Linear(action_dim, unet.time_embed_dim),
            nn.GELU(),
            nn.Linear(unet.time_embed_dim, unet.time_embed_dim)
        )
    
    def forward(self, noisy_latent, t, action_embed):
        """
        动作条件扩散去噪
        
        Args:
            noisy_latent: [B, T, C, H, W] 噪声潜变量
            t: 扩散时间步
            action_embed: [B, T, N, D] 动作嵌入
        
        Returns:
            denoised: [B, T, C, H, W] 去噪结果
        """
        # 投影动作嵌入到时间嵌入空间
        action_cond = self.action_projector(action_embed)
        
        # 通过交叉注意力注入
        denoised = self.unet(
            noisy_latent, 
            t, 
            context=action_cond,
            # 使用交叉注意力注入动作条件
        )
        
        return denoised
```

## 5. 局限性与未来方向

### 5.1 潜在局限性

| 局限性 | 描述 |
|--------|------|
| **单参考图像限制** | 复杂对象（如多视角外观变化大）可能重建不完整 |
| **长时一致性** | 超长时视频可能出现身份漂移 |
| **复杂交互** | 多 agent 复杂交互场景的建模可能不足 |
| **物理合理性** | 生成场景可能缺乏严格的物理约束 |
| **计算成本** | 视频扩散模型推理速度可能较慢 |

### 5.2 未来方向

1. **多参考图像融合**
   - 从多视角参考图像提取更完整身份
   - 提升复杂对象的身份一致性

2. **物理约束集成**
   - 引入车辆动力学约束
   - 确保生成场景的物理合理性

3. **更高效推理**
   - 蒸馏加速
   - 潜在空间压缩

4. **更复杂交互**
   - 多 agent 博弈建模
   - 社会行为模拟
